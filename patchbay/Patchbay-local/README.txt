PATCHBAY MIDI STUDIO - local copy
=================================

1. Unzip this folder anywhere (for example Documents\Patchbay).
2. Double-click Patchbay.html. It opens in your browser (Chrome or Edge work best).
3. The first time, the Sound library panel says the built-in sounds are "Not loaded".
   Click "Choose .sf2 file..." and pick sounds\GeneralUser-GS.sf2 from this folder.
   The browser keeps it, so you only do this once per browser.
4. Click Open MIDI (or drag a .mid file onto the window), then click any
   channel's instrument to swap it.

Add more instruments: "Add SoundFont (.sf2)" takes any .sf2 bank. Those are kept too.
Export WAV saves a 44.1 kHz / 16-bit stereo .wav of what you hear (solo a channel to export just that part).
Save session writes a .json file with each channel's instrument and mix settings.

Built-in sounds: GeneralUser GS 2.0.3 by S. Christian Collins
https://www.schristiancollins.com/generaluser  (license: sounds\GeneralUser-GS-LICENSE.txt)
