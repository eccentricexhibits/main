HOW TO USE WITH THE ORIGINAL FONT WEIGHTS
- Extract the ORIGINAL Editorial Complete handoff.
- Copy this package's Source/dist/app.js, Source/dist/editorial-event-identity.css,
  and the four page HTML files over the corresponding files in the ORIGINAL Source/dist folder.
- Keep your existing ORIGINAL Source/dist/fonts folder in place. This ensures Karbon Regular,
  Medium, Semibold, and Bold display exactly as in the original mockup.
- Double-click Source/dist/index.html, or use OPEN_INTERACTIVE_PREVIEW.html to see desktop/mobile.
- Fonts are not redistributed in this package. The ZIP is intentionally compatible with
  fonts already in your ORIGINAL handoff.
