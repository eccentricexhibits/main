I'm continuing work on a set of event wayfinding maps for a Vector Institute
event at the Design Exchange, 234 Bay Street, Toronto. The files in this repo
are the current state. Please start by reading HANDOFF.md in full — it exists
so you don't have to re-derive what was already worked out, and it will save
you from several traps.

The single most important thing in it: north points to the RIGHT on every
Design Exchange blueprint, not up. Getting that wrong silently produces maps
that look plausible and are wrong. Section 4 explains the mapping and the
rotation the finished sheets use. Do not assume north is up, and do not
"correct" the tech deck's compass wall names — they are right once the
orientation is understood, and an earlier version of this project wrongly
flagged them as a venue error.

How the files are named:
- "Claude Code - ..." = finished output from this project.
- "Venue Supplied Plans - Level N - From Blueprints" = the venue's blueprints.
  This is the authority for wall geometry, dimensions, room names and the
  north arrow.
- "Venue Supplied Plans - Level N - <layout> + 3D Mockups" = the event team's
  own layout plans plus 3D renders. Every page is a raster, so anything taken
  from them is traced, not measured.
- "Design Exchange - Tech Deck" = projection surfaces, LED sign specs,
  lighting and audio inventory.

How to make changes: these sheets are generated by Python, not drawn by hand.
Editing a PDF or SVG produces a change the next build discards. The generator
is at eccentricexhibits/main, branch claude/design-exchange-floor-maps-0icdz3,
under floor-maps/. Clone that, edit the relevant data module (lobby_data.py,
trading_data.py, gallery_data.py, overview_data.py) and re-run the build.
HANDOFF section 6 documents the schema, section 7 has recipes for common
edits. If you can't reach that repo, tell me rather than hand-editing an
export.

Before changing anything traced from the venue's material — the vendor tables
on the Gallery sheet, the seating on the Trading Floor, any projection wall —
read sections 4 and 9 first. Several of those carry deliberate limits on how
precise the drawing claims to be, and tightening them would be false precision
rather than an improvement.

Section 9 lists open questions never resolved with the venue. If your task
touches one, flag it rather than guessing.
