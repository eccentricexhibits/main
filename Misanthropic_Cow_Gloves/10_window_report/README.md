# GLOVES window report

Process report for the Claude window that built the hoof gloves, written for the Misanthropic Cow master document
(user's template, sections 0–12; [RECORDED]/[INFERRED]/[UNKNOWN]/[ESTIMATED] labels).

- `GLOVES_window_report.md` / `.pdf`: the report (the PDF embeds the key figures next to the method steps, downscaled).
- `GLOVES_figures.csv`: the figure register (203 figures, GLOVES-F001 … F203) with size, MD5, source and provenance.
- The figures themselves (198 MB at original resolution) are not in the repo; they were delivered as
  `GLOVES_figures_part1of8.zip` … `part8of8.zip` (each < 29 MB).
